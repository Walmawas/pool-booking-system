# UI

- Preserve Arabic RTL as the primary layout direction.
- Optimize for mobile first, then tablet and desktop.
- Keep public browsing simple and fast.
- Keep admin workflows efficient and visually distinct from the public storefront.
- Reuse existing Tailwind patterns and components before introducing new dependencies.
- Preserve accessibility: labels, focus states, keyboard interaction, contrast, and semantic buttons/links.
- Do not alter Firebase business logic merely to change visual presentation.
